# Учебные проекты по Python

Репозиторий с домашними заданиями и учебными проектами.

## Структура репозитория

```
Модуль 3/
├── Часть 1/
│   ├── задание_1.py   — работа с диапазонами чисел
│   ├── задание_2.py   — работа с диапазонами
│   ├── задание_3.py   — работа с диапазонами
│   └── задание_3_альтернатива.py — площадь ромба
└── Часть 2/
    ├── задание_1.py   — диапазоны
    ├── задание_2.py   — строки и символы
    ├── задание_3.py   — цикл с условием
    └── задание_4.py   — сумма и минимум/максимум
```

## Модуль 3

### Часть 1
Задания на работу с числами, диапазонами и математическими формулами.

### Часть 2
Задания на работу со строками, циклами и условными операторами.

## Запуск

python "Модуль 3/Часть 1/задание_1.py"
